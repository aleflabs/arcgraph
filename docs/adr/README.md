# Decisions carried by `v0.1.0-beta`

Only decisions that describe the retained bare database runtime are published
here:

- [`ADR-004`](ADR-004-mcp-tool-catalog.md): six-tool MCP catalog
- [`ADR-011`](ADR-011-tenant-isolation.md): tenant isolation
- [`ADR-018`](ADR-018-current-mvcc-records.md): current MVCC visibility and no
  temporal query grammar
- [`ADR-023`](ADR-023-index-read-accelerators.md): indexes are accelerators,
  not visibility authorities
- [`ADR-035`](ADR-035-vector-index.md): vector index boundary
- [`ADR-037`](ADR-037-transport-routing.md): stdio, HTTPS, and Bolt routing
- [`ADR-039`](ADR-039-bm25-text-search.md): BM25 boundary
- [`ADR-040`](ADR-040-community-index.md): internal community membership index

Milestone plans, future-product proposals, and decisions for removed
capabilities are deliberately absent from this distribution.
